# Barbershop Appointment Bot ✂️

An automated Telegram bot designed for barbershops and beauty salons to handle client appointments 24/7. It allows customers to browse services and book time slots directly in Telegram, reducing the workload on administrators.

## ✨ Features
- **Easy Booking:** Simple interaction using Telegram Inline buttons.
- **Service Menu:** Displays available services and prices.
- **Appointment Tracking:** Saves all bookings with client names, services, and times to an SQLite database.
- **Admin Ready:** Streamlined flow to ensure no booking is missed.

## 🛠 Tech Stack
- Python
- `python-telegram-bot`
- SQLite3
- `python-dotenv`
